# TokScript-style roadmap

The next useful clean-room tools, in order:

1. `download_videos_bulk`
2. `transcribe_bulk`
3. `download_cover_image`
4. `download_cover_images_bulk`
5. `get_stored_video`
6. `get_library_stats`
7. `get_user_library`
8. `submit_transcript_job`
9. `get_job_status`
10. `preview_results`
11. `export_results`

Instagram and YouTube can be added behind the same normalized media interface.

Do not build all of them first. Validate profile discovery + download + transcript reliability before expanding.
